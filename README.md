# YKW1 PC EDITION
### Provided to you by tsukiyom

##Goal of the project:
-Having a stable version of Yo kai watch 1 on pc that support console with the SDL library 
-Having a good optimisation for a good playthrough with the same performances delivered by the switch 1 and more (60 fps and else)
-Importing an internet battle system while having a Data Base that will manage the score for a future ranked mode (Coming after the beta release)
-Having a discord bot that display your stats
